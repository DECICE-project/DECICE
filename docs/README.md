# DECICE - WP3
Dedicated repository for WP3.

## Usage
Utilize it to your needs, create a folder structure or add sub-repositories as required. 
Keep in mind, that this repository must be usable for all project members in the long term.

## Submodules

### Add Submodule Initialization on Clone
`git clone --recurse-submodules <repo-url>`

If already cloned without submodules, initialize them manually:

`git submodule update --init --recursive`
